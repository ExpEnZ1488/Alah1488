# Робо-рука SocialTech

Рука на 6 осей высотой ~56 см (в вытянутом вверх положении). Детали печатаются на 3D-принтере (проверено под Bambu Lab P1S, стол 256×256 мм). Управление с геймпада PS5 через ESP32.

| | |
|---|---|
| Оси | поворот основания 360°, плечо, локоть, наклон запястья, вращение кисти, захват |
| Груз | старт ~300–500 г, после замены моторов до 1 кг |
| Захват | раскрытие до ~70 мм (берёт банку 0,33 л), червячный привод не разжимается сам |
| Пластик | ~920 г PETG + немного PLA Silk и TPU |
| Печатных деталей | 27 |

## Файлы

- `cad/model.py` — параметрическая модель (Python). Все размеры в начале файла.
- `stl/` — готовые детали для печати, уже повёрнуты для стола.
- `viewer/` — 3D-просмотрщик.

Пересобрать после изменения размеров:

```bash
pip install manifold3d numpy
python3 cad/model.py
```

> ⚠️ Размеры сервоприводов в модели примерные. Перед печатью держателей
> (05, 07, 09) и блоков с гнёздами (10, 11) измерь свои моторы штангенциркулем
> и поправь `SERVO_STD` / `SERVO_BIG` в `cad/model.py`.

## Безопасность

- Аварийная кнопка всегда под рукой: она обесточивает все моторы.
- Не держи пальцы в захвате, когда рука включена. Червяк сжимает сильно.
- Сервоприводы питаются только от преобразователя, не от ESP32.
